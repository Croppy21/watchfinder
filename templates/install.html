How to add WatchFinder

Add WatchFinder to your home screen and use it like an app.

iPhone & iPad

  1. Open WatchFinder in Safari.
  2. Tap the Share button.
  3. Select Add to Home Screen.
  4. Turn on Open as Web App.
  5. Tap Add.

Android

  1. Open WatchFinder in Chrome.
  2. Tap the ⋮ menu.
  3. Select Add to Home screen or Install app.
  4. Follow the instructions to add WatchFinder.
